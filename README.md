# Suppwise

Карта добавок: что для чего принимают, что с чем сочетается, когда принимать.
Статический сайт без сборки и без зависимостей.

Сейчас это **база**, а не готовый продукт. План развития — в [ROADMAP.md](ROADMAP.md).

## Запуск

Открыть `index.html` в браузере. Сервер не нужен.

Приветственный экран показывается один раз. Чтобы увидеть его снова, добавь `?welcome` к адресу.

## Структура

```
index.html            разметка вкладок и приветственного экрана
css/app.css           все стили
data/supplements.js   добавки (N), цели (G), связи (E), описания (INFO), английские названия
data/sources.js       источники (PubMed) для связей
data/plan.js          слоты расписания и готовые наборы (STACKS)
data/training.js      карточки тренировок
data/problems.js      раздел «Проблемы»
js/app.js             логика: карта, карточки, таблица связей, расписание
js/notes.js           вкладка «Записи»
```

Файлы в `data/` — обычные скрипты с константами, а не JSON: так сайт открывается
прямо с диска. Когда появится сервер, они переедут в JSON и API.

## Как устроены данные

- **Добавка** (`N`): `id`, символ `s`, название `name`, цели `g`, подсказка по приёму `tip`.
- **Связь** (`E`): `[добавка, добавка, тип, уровень данных, текст]`.
  Тип: `syn` помогают, `anti` мешают, `warn` зависит от дозы. Уровень: `A`, `B`, `C`.
- **Цель** (`G`): название, цвет, пояснение.
- **`DEFONLY`**: пары «добавка — цель», где эффект есть только при дефиците (на карте пунктир).

## Ссылки на карте

- `#s-Mg` открывает добавку, `#g-sleep` открывает цель.
- `#links`, `#problems`, `#plan`, `#train` открывают вкладки.
