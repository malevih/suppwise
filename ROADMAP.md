## 1. База: доделать

- [ ] Проверить всё на реальном телефоне (пока проверено только в эмуляции)
- [ ] Решить, оставляем ли вид «Все связи» на карте или только таблицей
- [ ] Красная метка у добавок с конфликтами (обсуждали, отложили)
- [ ] Плюсик «добавить» для целей и проблем: определить, что он делает

## 2. Доверие

- [ ] Ссылки на PubMed для каждой связи (начать с уровней A и B)
- [ ] Уровень данных A/B/C для каждой пары «добавка — цель»
- [ ] Толщина линий к целям по уровню данных
- [ ] Перепроверить разметку «только при дефиците» по источникам
- [ ] Поправить тексты там, где источник говорит другое

## 3. Содержание

- [ ] Пересмотреть «Проблемы»: добавить «нет сил по утрам», сниженное настроение
      (с блоком «когда к врачу»)
- [ ] Расписание от проблемы: выбрал проблему — получил план приёма
- [ ] Недельный план (день недели: зал, питание, добавки), пока в браузере без аккаунта
- [ ] Новые добавки по результатам research
- [ ] Вкладка с диетами (кето, средиземноморская и другие)

## Открытые вопросы

- Что платно, что бесплатно. Рабочая гипотеза: карта и связи бесплатно;
  «Мой набор» с проверкой конфликтов, расписание и источники по подписке.
- Название продукта. `suppwise` — рабочее имя репозитория.
